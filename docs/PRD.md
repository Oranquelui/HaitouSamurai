## 1. プロダクト概要

配当サムライは、日本の個人投資家が「税引後で毎月いくら残るか」と「配当を続けられそうか」を、公開用の試算データで確認する教育・研究用サンプルです。

投資助言・銘柄推奨ではなく、配当リサーチの前提確認、数値の見方、一次情報で確認すべき観点を整理するためのサンプルとして位置づけます。

## 2. 現在のゴール

v1.1.0 のゴールは、公開レビューに耐える日本語中心の MVP として、次を満たすことです。

- 初見の閲覧者が、配当サムライの目的を短時間で理解できる。
- 公開サンプル URL から LP と試算画面を確認できる。
- 配当利回りだけでなく、配当性向、収益性、負債、成長性などを含む配当継続力の見方を示す。
- 日本の課税口座を想定した 20.315% の税引後配当試算を表示する。
- 投資助言ではないこと、データが簡易・静的・試算用であることを明示する。
- リポジトリを採用・ポートフォリオ・技術レビューで確認しやすい状態にする。

## 3. 対象ユーザー

### Primary

- 日本語で配当投資の候補を調べたい個人投資家
- 高配当銘柄の「利回りは高いが大丈夫か」を数値で確認したい人
- 税引後の手取り配当をざっくり把握したい人

### Secondary

- プロダクト・データ・フロントエンド実装を確認する採用担当者、レビュー担当者、開発者
- Python data core + TypeScript / Next.js UI の構成を確認したい人

## 4. ユーザー課題

- 税引前利回りだけでは、実際に毎月いくら残るか分かりにくい。
- 高利回り銘柄が、配当性向・利益・負債・成長性の面で危ない可能性を見落としやすい。
- 複数銘柄を同じ前提で比較しにくい。
- 投資判断前に、何を一次情報で確認すべきかが整理されていない。

## 5. v1.1.0 の実装済み範囲

- 日本語 LP
- `/dashboard` の配当試算画面
- 複数銘柄選択
- 検索・並び替え可能な配当メトリクス表
- 配当継続力スコア
- 配当継続力マップ
- 日本の上場株式等を想定した 20.315% の税引後試算
- 年間手取り、毎月手取り、月5万円までの不足額、必要元本の目安
- 簡易的な月別配当カレンダー
- 試算用データ・非助言の明示
- 日本語 README
- GitHub Release `v1.1.0`
- main branch の最小保護

## 6. 非ゴール / やらないこと

v1.1.0 では以下を提供しません。

- 投資助言
- 金融助言
- 銘柄推奨
- 売買推奨
- Buy / Sell / Hold 表現
- 個別ポートフォリオ助言
- リアルタイム市場データ
- 有料機能
- 収益・配当・FIRE 達成の保証
- 実際の配当月を保証するカレンダー

## 7. 信頼境界と法務ガードレール

- 表示データは教育・研究用の試算データである。
- スコアは投資判断ではなく、確認観点の整理である。
- ユーザーは金融データ、市場データ、税制、為替、企業情報、配当情報を一次情報で確認する必要がある。
- 有料機能、ライブデータ、個別化機能を出す前に法務確認を行う。
- UI コピーでは「安全」「おすすめ」「買い」「売り」「保有」などの助言に見える語を避ける。

## 9. 今後の方向性

優先順位は、投資判断機能ではなく「確認ワークフロー」と「公開レビューしやすい証拠」を強化する方向です。

- README スクリーンショット / GIF の追加
- データ出典と更新手順の明確化
- 試算データの provenance / assumption 記録
- ユーザー自身の分析用 CSV export
- localStorage ベースの保存シナリオ
- watchlist / saved scenario の UX 検証
- CI で lint / test / build / audit を自動化
- 有料・ライブデータ・個別化の前の法務レビュー
